# Meerkat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, read-only web app at http://localhost:4321 that shows the user's Herdr agent sessions in three live columns (Needs attention, Working, Idle) and each session's last ~40 lines of output on demand.

**Architecture:** One Node 24 process. A Herdr client talks NDJSON over the Unix socket `~/.config/herdr/herdr.sock` through a method allow-list; a supervisor keeps a pure board state up to date from a snapshot plus `pane.agent_status_changed` events, reconnecting when Herdr goes away; a `node:http` server pushes the board over SSE to a React + Vite page and serves output reads.

**Tech Stack:** TypeScript, Node 24.22.3, `node:http`/`node:net` (no server framework), React + Vite, Vitest (+ jsdom, Testing Library), ESLint (typescript-eslint, react-hooks), Prettier, Playwright (chromium), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-21-meerkat-design.md` (read it first; its "Herdr protocol" section has the verified wire shapes this plan relies on).

## Global Constraints

- Node pinned to exactly `24.22.3`: `"volta": { "node": "24.22.3" }` in `package.json`, `node-version: '24.22.3'` on every `actions/setup-node` step; `scripts/check-node-pins.sh` enforces both.
- No code comments at all. Only build directives (e.g. a shebang) are allowed.
- Never suppress lint or type errors (no `eslint-disable`, `@ts-ignore`, `@ts-expect-error`, rule switched off for one place). Fix the code.
- Red/green TDD: every step that adds behaviour starts with a failing test that is run and seen to fail.
- Prettier config copied from owlet: `{"semi": false, "singleQuote": true, "trailingComma": "es5", "printWidth": 100, "tabWidth": 2}`.
- Herdr: only methods in `ALLOWED_METHODS` = `session.snapshot`, `events.subscribe`, `events.wait`, `agent.list`, `agent.get`, `agent.read`. During development never run bare `herdr`, never `herdr server stop`, never call a mutating method. Tests never touch the real socket; they use the fake Herdr from Task 3.
- Server binds `127.0.0.1` only, port `MEERKAT_PORT` (default `4321`). Allowed `Host` header values: exactly `localhost:<port>` and `127.0.0.1:<port>`. No CORS headers ever. Only `GET`.
- Install nothing outside this worktree without asking the user (npm installs inside the worktree are fine). owlet is read-only.
- Don't kill processes you didn't start. If a port is taken (4321 or the e2e port 43219), report it and stop; don't kill the holder.
- Mac only; no phone access, sign-in, prompts, notifications, auto-start, or deploy.
- Copy: column titles `Needs attention`, `Working`, `Idle`; unnamed session `(unnamed)`; banners `Herdr is not reachable — showing last known state` and `Meerkat server not reachable — retrying`; drawer closed state `Session closed`.

## Review Focus

1. **Herdr restarts while Meerkat is streaming**: the board shows the disconnected banner within one backoff step, then rebuilds from a fresh snapshot without a Meerkat restart. Pinned in Task 6 (`recovers after Herdr restarts mid-stream`) and Task 11 (e2e restart spec).
2. **A malicious website open in the same browser tries to read localhost** (DNS rebinding with `Host: evil.example:4321`, or a cross-origin `fetch`/`EventSource`): Meerkat answers 421 on a foreign Host and never sends `Access-Control-Allow-*` headers, including on `OPTIONS` and on the SSE route. Pinned in Task 7.
3. **ANSI escapes and HTML-looking text in output**: leftover CSI/OSC sequences are stripped server-side, and `<b>`/`<script>` show literally in the drawer. Pinned in Task 5 and Task 10.
4. **A session closes while its output drawer is open**: the drawer says `Session closed`, keeps the last text it fetched, and disables refresh; the output route returns 404 on `agent_not_found`. Pinned in Task 7 and Task 10.
5. **Huge output and 50+ sessions**: output is capped at 64 KB keeping the end, on a UTF-8 boundary; 60 sessions are subscribed in one `events.subscribe` request and all 60 cards render. Pinned in Task 3, Task 5, Task 6 and Task 11.

- Produces: `isAllowedHost(host: string | undefined, port: number): boolean`; `createHttpServer(opts: { supervisor: Pick<Supervisor, 'current' | 'onChange'>; client: HerdrClient; port: number; staticDir: string; heartbeatMs?: number }): http.Server` (default `heartbeatMs` 15000); `class PortInUseError extends Error`; `listen(server: http.Server, port: number): Promise<void>` (binds `127.0.0.1`; `EADDRINUSE` → `PortInUseError` with the message `Port <port> is already in use.
